# Import Bundle จาก Item ID บน Aztek

หน้า **Bundle** มีส่วน **Import Bundle จาก Item ID** สำหรับจัดไอเทมที่มี ID แล้วเข้าคิว โดยไม่ต้องค้นหาผ่าน Item Finder

1. เลือกเกม / เซิร์ฟให้ตรงกับ Item ID แล้วกด **ดาวน์โหลด Template Excel**
2. ใช้รูปแบบชุดตามตัวอย่างด้านล่าง เปลี่ยนช่อง `[Item ID]` และ `[ชื่อ Currency]` ในเทมเพลตเป็นค่าจริง พร้อมตรวจชื่อ จำนวน และเรทตัวอย่าง
3. ก็อปเซลล์คอลัมน์ A:D มาวางแล้วกด **พรีวิวข้อความที่วาง** หรือเลือกไฟล์ `.xlsx` แล้วกด **อ่านไฟล์** เลือก Sheet ตามชื่อจริง
4. กด **พรีวิวข้อมูล** ตรวจชื่อบันเดิล Item ID จำนวน และ Tier
5. กด **เพิ่มเข้าคิว Bundle** แล้วแก้ไขรายละเอียดต่อในคิวเดิม

```text
กล่องสุ่มกิจกรรม	RANDOM
200479	10	Common	60
200480	3	Rare	30
200481	1	Epic	10

แพ็กแจกของ	FIXED
200479	5	Common
CREDIT: Alz	100000	Common
```

หัวชุดมีชื่อบันเดิลและประเภทในคอลัมน์ A:B รายการแต่ละแถวมี Item ID / จำนวน / Rarity / เรทสุ่ม ในคอลัมน์ A:D เว้นแถวว่างระหว่างชุดได้

- ใช้ Tab ที่ติดมากับการก็อปจาก Excel หรือคั่นด้วย `|` ไม่แยกชื่อด้วยช่องว่างธรรมดา
- ประเภท: FIXED, CHOICE, RANDOM โดย RANDOM ต้องมีเรททุกแถวรวมทั้ง Currency และรวมกัน 100% ส่วน FIXED/CHOICE เว้นคอลัมน์เรท
- Item ID และจำนวนเป็นจำนวนเต็มบวกไม่เกิน 12 หลัก จำนวนว่างใช้ 1
- Rarity: Common, Rare, Epic, Mystic, Legend ว่างใช้ Common
- Currency ระบุชนิดนำหน้า: `CREDIT: ชื่อ`, `DEBIT: ชื่อ`, `MILEAGE: ชื่อ`, `PLAYER_EXP: ชื่อ`
- ไม่ดึงหรือยืนยันชื่อ Currency จาก Aztek ระหว่าง Import
- ยังอ่านเทมเพลตแถวเรียบรุ่นแรกที่มีหัว `Bundle Name / Item ID / Qty / Tier / Item Name` ได้ โดยรวมชื่อเดียวกันใน Sheet และใช้ FIXED

แต่ละแถวเป็นหนึ่งไอเทมและคงลำดับตามไฟล์ Item ID ซ้ำข้ามบันเดิลได้ แต่ถ้าซ้ำภายในบันเดิลเดียวกันต้องรวมจำนวนเองก่อน Import

นำเข้าตามประเภทที่ระบุและเปิดส่งทันทีตามค่าเริ่มต้นของหน้า Bundle สามารถแก้ประเภท ปริมาณ Tier เรทสุ่ม และ Reward ในคิวได้ การ Import ไม่เปิด Aztek ไม่ตรวจว่า ID มีจริง และไม่สร้างข้อมูลจริงจนผู้ใช้กดสร้างเอง

หากชื่อชนกับคิวเดิม ระบบเติม `(2)`, `(3)` และแสดงชื่อที่จะใช้ในพรีวิว หากแก้คิวจนชื่อชนกันหลังพรีวิวต้องพรีวิวใหม่ คิวเดิมไม่ถูกแทนที่

## ข้อจำกัดและข้อผิดพลาด

- อ่านเฉพาะ Sheet ที่ไม่ถูกซ่อน เลือกนำเข้าได้ครั้งละหนึ่ง Sheet และเลือก Sheet อื่นต่อได้
- ต้องเป็น `.xlsx` ขนาดไม่เกิน 32 MB สูงสุด 50 Sheet ที่มองเห็น และ 10,000 แถวต่อ Sheet
- สูงสุด 200 ไอเทมต่อบันเดิล ไม่รองรับสูตรหรือค่า Error ให้ใช้ Paste Values ก่อน
- ถ้ามีแถวผิด จะไม่เพิ่มข้อมูลบางส่วนของ Sheet นั้น ระบบแจ้งเลขแถว Excel ให้แก้แล้วอ่านไฟล์ใหม่
- พรีวิวเป็นข้อมูลชั่วคราว เพิ่มเข้าคิวแล้วจึงบันทึกในเบราว์เซอร์ ปุ่มเพิ่มป้องกันการกดซ้ำใน Sheet เดิมจนกว่าจะอ่านไฟล์ใหม่
- หากพื้นที่บันทึกเบราว์เซอร์เต็ม จะไม่เปลี่ยนคิวเดิมและสามารถลองเพิ่มอีกครั้งได้

## จุดแก้ไขสำหรับผู้พัฒนา

- `web/bundle_import.py`: อ่านและตรวจ Template ไม่เชื่อมต่อ Aztek
- `web/static/bundle_import.js`: เลือก Sheet พรีวิว จัดชื่อ และเพิ่มเข้าคิว
- `web/static/templates/bundle-template.xlsx`: เทมเพลตที่แจกและรวมใน Setup โดย `local_web.spec`
- API: `GET /api/bundles/template`, `POST /api/bundles/import`, `POST /api/bundles/import-text` ต้องมี session ผู้ใช้
- เทสต์: `tests/test_web_bundle_import.py`, `tests/test_web_bundle_import_ui.py`, `tests/test_web_bundle_bulk.py`, `tests/test_web_bundle_bulk_ui.py`
