# 02: ดาวน์โหลด Setup ผ่านโปรแกรมพร้อมตรวจไฟล์และลองใหม่

ดำเนินการใน Local checkout แล้ว; หลักฐาน: `docs/verification/2026-09-14-local-auto-update.md`

## What to build

ต่อจาก Update Details Popup ให้ผู้ใช้กดดาวน์โหลด Setup เต็มและเห็นความคืบหน้าจริง เมื่อโหลดครบและตรวจ SHA-256 ผ่านให้แสดงว่าไฟล์พร้อม หากเครือข่ายหรือไฟล์มีปัญหาให้แสดงสาเหตุและลองใหม่โดยยังใช้โปรแกรมเดิมได้

ใช้สถานะอัปเดตร่วมจากงาน 01 เพื่อไม่ดาวน์โหลดซ้อนจากหลายแท็บ งานนี้จบที่ไฟล์พร้อม ไม่ปิดโปรแกรมหรือเรียกตัวติดตั้งจนกว่างาน 04 จะเชื่อมการตรวจงานว่างและการเก็บร่างครบ

## Acceptance criteria

- [ ] ดาวน์โหลดเริ่มจากการกดของผู้ใช้เท่านั้น ปิด popup หรือพบ Release ใหม่ไม่เริ่มดาวน์โหลดเอง
- [ ] รับแพ็กเกจและ checksum เฉพาะ Release ของ `momozxmo/tool-cabal-local` ผ่าน HTTPS ตรวจแหล่ง redirect ที่อนุญาต และไม่รับ executable URL/path/คำสั่ง shell ตามอำเภอใจจาก client
- [ ] คำสั่งเปลี่ยนสถานะผ่าน Local session และการป้องกัน request ข้าม origin เดิม โหมดที่ไม่รองรับปฏิเสธแม้เรียก API โดยตรง
- [ ] ดาวน์โหลดลงพื้นที่ชั่วคราวของงานอัปเดต แสดง bytes/ความคืบหน้าที่ทราบจริงและสถานะกำลังตรวจไฟล์
- [ ] ไฟล์ครบและ SHA-256 ตรงเท่านั้นจึงเป็นไฟล์พร้อม ผูกไฟล์กับรุ่นเป้าหมาย ไม่สลับไปใช้ไฟล์ของรุ่นอื่น
- [ ] Release ไม่มี asset/checksum, checksum ไม่ตรง, ไฟล์ขาด, เน็ตหลุด หรือพื้นที่เขียนไม่ได้ ต้องไม่ทำให้ไฟล์เสียเป็นไฟล์พร้อม และไม่เรียก Setup
- [ ] ข้อผิดพลาดเป็นภาษาไทย มีปุ่มลองใหม่ ไม่เปิดเผย secrets และโปรแกรมเดิมยังทำงานได้
- [ ] กดซ้ำหรือกดพร้อมกันจากหลายแท็บเกิดการดาวน์โหลดเดียว ทุกแท็บแสดงสถานะร่วมกัน
- [ ] เปิดใหม่หลังดาวน์โหลดถูกขัดจังหวะแล้วไม่ติดสถานะ downloading ตลอดไป ไม่ใช้ไฟล์ชั่วคราวโดยไม่ตรวจครบก่อน และลองดาวน์โหลดใหม่ได้โดยไม่ต้องมีระบบ resume แบบแบ่งส่วน
- [ ] ทดสอบผ่าน UI/Local workflow กับแหล่งดาวน์โหลดจำลอง รวม malformed Release, hash mismatch, redirect ที่ไม่อนุญาต, offline, duplicate request และการเปิด runtime ใหม่
