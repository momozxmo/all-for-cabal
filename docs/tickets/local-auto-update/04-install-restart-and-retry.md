# 04: ติดตั้งอัปเดต เปิดโปรแกรมกลับ และลองใหม่เมื่อผิดพลาด

ดำเนินการใน Local checkout แล้ว; หลักฐานและข้อจำกัดการตรวจ Windows: `docs/verification/2026-09-14-local-auto-update.md`

## What to build

เชื่อมปุ่มอัปเดตจาก popup ไปจนถึงการติดตั้งและกลับมาใช้งานจริง โดยใช้ไฟล์ที่ตรวจแล้วจากงาน 02 และขั้นเตรียมงาน/ร่างจากงาน 03 เมื่อพร้อมให้ปิดโปรแกรมอย่างสุภาพ ตัวช่วยติดตั้งรันต่อหลัง Launcher เดิมปิด เรียก Setup โดยไม่ต้องเดิน wizard แล้วเปิดโปรแกรมรุ่นเป้าหมายกลับ

หากปิด ติดตั้ง หรือเปิดกลับไม่สำเร็จ ต้องแสดงข้อผิดพลาดตามขั้นตอนที่เกิดจริง มีช่องทางลองใหม่ที่ยังใช้ได้แม้เว็บหลักไม่ทำงาน และรักษาข้อมูลผู้ใช้เดิม รุ่นแรกไม่มี rollback อัตโนมัติ

## Acceptance criteria

- [ ] กดอัปเดตเริ่ม workflow ครบ: ตรวจงาน/ร่าง ดาวน์โหลดและตรวจไฟล์ ตรวจความพร้อมซ้ำก่อนติดตั้ง ปิด ติดตั้ง และเปิดกลับ โดยไม่บังคับผู้ใช้เดิน Setup เองตามปกติ
- [ ] ถ้ามีงานตั้งแต่กด ให้แจ้งรอและไม่ดำเนินการติดตั้ง หากมีงานเริ่มระหว่างดาวน์โหลดให้ตรวจพบก่อนติดตั้ง ต้องกดใหม่หลังงานจบ ไม่มีการติดตั้งอัตโนมัติเมื่อคิวจบ
- [ ] เรียก Setup ได้เฉพาะรุ่น/ไฟล์ที่ตรวจผ่านและผลการเตรียมพร้อมที่ยังถูกต้อง คำสั่งที่ไม่มี Local session/origin ถูกต้องหรือมาจากโหมดไม่รองรับถูกปฏิเสธ
- [ ] ปิด server/Launcher และ process ที่โปรแกรมดูแลอย่างสุภาพ ตรวจว่าหยุดจริง ถ้าหยุดไม่ได้ไม่เริ่ม Setup และไม่ใช้การบังคับฆ่างานแทนการตรวจ
- [ ] ตัวช่วยยังทำงานได้หลัง Launcher เดิมปิดและระหว่างไฟล์โปรแกรมถูกแทนที่ ไม่รันซ้อนเมื่อกดซ้ำจากหลายแท็บ/หลาย instance
- [ ] ติดตั้งสำเร็จแล้วเปิด Launcher กลับผ่านช่องทาง Local เดิม รักษา origin และร่าง/คิวที่เก็บไว้ ไม่ส่งงานไป Aztek เอง
- [ ] ตรวจ exit ของ Setup และ health/runtime version เป้าหมายก่อนรายงานสำเร็จ แยกการติดตั้งล้มเหลวจากกรณีติดตั้งได้แต่เปิดหน้าเว็บไม่สำเร็จ
- [ ] ฐานข้อมูล config กุญแจเข้ารหัส และ session ที่บันทึกไว้ยังอ่านได้ ใช้การสำรอง/migration เดิม ตรวจด้วยข้อมูลจำลอง ไม่อ้างว่า session ที่ Aztek ทำให้หมดอายุจะกลับมาใช้ได้
- [ ] ข้อผิดพลาดก่อนติดตั้งปลดการกั้นและใช้รุ่นเดิมได้ ข้อผิดพลาดหลังแทนที่ไฟล์บางส่วนมีข้อความและ retry ผ่านตัวช่วยที่ไม่พึ่งเว็บหลัก ไม่อ้างว่ารุ่นเดิมยังเปิดได้เสมอ
- [ ] เปิดหลังการอัปเดตถูกขัดจังหวะแล้วตรวจสภาพจริง รายงาน/ลองใหม่ได้ ไม่ค้างสถานะติดตั้ง ไม่รันไฟล์ที่ยังไม่ผ่านการตรวจ และไม่เปิดเผย secrets ใน log
- [ ] รวม automated workflow tests โดยจำลองเฉพาะ Release/download/process ที่ขอบระบบ แต่ใช้ตรรกะเตรียมงานและเก็บร่างจริง ตรวจ failure ก่อนปิด หลังปิด exit ล้มเหลว health timeout และเวอร์ชันผิด
- [ ] Build แพ็กเกจสำหรับทดสอบที่มีตัวช่วยครบ และทดสอบบน Windows แยกด้วยรุ่นที่มี updater แล้วอัปเกรดไปอีกรุ่นจริง ตรวจ retry และข้อมูลจำลองโดยไม่แทนที่โปรแกรมผลิตหรือสร้างข้อมูลจริงใน Aztek
- [ ] คู่มืออธิบายว่าผู้ใช้เดิมต้องลง Setup ที่มี updater อีกหนึ่งครั้ง การอัปเดตใช้ Setup เต็ม และขั้นตอนซ่อมเมื่อติดตั้งพลาด ไม่มี delta/rollback/หน้าประวัติ/บริการกลางเพิ่ม

## Blocked by

- 02: ดาวน์โหลด Setup ผ่านโปรแกรมพร้อมตรวจไฟล์และลองใหม่
- 03: เตรียมอัปเดตโดยรักษางาน ร่าง และคิวทุกหน้า
