# New Item #12 — พัฒนาและทดสอบในเครื่องครบแล้ว

อัปเดต28ตุลาคม2026: ผลพัฒนาจบ17:47น. และส่งมอบในSetup0.1.43แล้ว พร้อมปิดGitHub#12เวลา18:22:45น. ขอบเขตการทดสอบในเครื่องไม่ใช่การรับรองทุกlivevariant

## ใช้งานส่วนใดได้แล้ว

- นำเข้า Excel แบบเลือก Sheet หรือรับเฉพาะรายการที่ Finder หาไม่พบ แล้วแก้และยืนยันร่างทีละแถว
- ค้น Item เดิมก่อนสร้าง ผู้ใช้เลือก ID เดิมหรือยืนยันสร้างใหม่เอง ไม่มีการเลือกหรือสร้างให้อัตโนมัติ
- สร้างเฉพาะรายการที่เลือก อ่านค่าที่บันทึกกลับมาเทียบต้นฉบับ และส่งเฉพาะผลผ่านที่เลือกไป Finder/Bundle โดยคง Amt และแถวอ้างอิง
- รวมร่างที่ค่าที่ใช้สร้างตรงกันทั้งหมดได้ แต่ยังเก็บผลเทียบและต้นทางของแต่ละแถวแยกกัน
- ถ้าคำตอบไม่แน่นอนต้องหยุด ไม่สร้างซ้ำ กู้ ID ได้เฉพาะเมื่อโปรแกรมเก็บคำตอบเดิมที่ผูกกับรายการนั้นไว้ แล้วอ่านตรวจใหม่
- ดูประวัติแต่ละรอบได้ การรับทราบปัญหาไม่เปลี่ยนผลให้ผ่านและไม่ปลดล็อกส่งต่อรายการที่ยังมีปัญหา

## ข้อจำกัดที่ต้องรู้

- มีmanualGENERALreceiptและอ่านค่าบันทึกจริงครบ4เกมแล้ว แต่ชุดอัตโนมัติทดสอบกับเว็บจำลอง ไม่อ้างว่ารองรับทุกlivevariant
- PC Premiumอ้างอิงfrontend sourceและฟอร์มจริงที่อนุญาตให้อ่าน รวมกับlocaltests ไม่มีการสร้างPremiumจริงเพื่อเก็บตัวอย่าง
- รูปตรวจไฟล์ส่วนตัวและสถานะว่ามีรูป ไม่พิสูจน์ภาพเหมือนกันระดับพิกเซล และไม่มีliveimageupload acceptance
