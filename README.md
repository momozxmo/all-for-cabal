# All for Cabal — Toolkit

## ติดตั้งเว็บแบบ Local สำหรับทีม

ทีมสามารถดาวน์โหลด Setup แล้วติดตั้งบน Windows 10/11 x64 ได้โดยไม่ต้องลง
Python หรือ Docker โปรแกรมเปิดเว็บ local ให้อัตโนมัติและไม่มีหน้าล็อกอินของ
All for Cabal ดูขั้นตอนติดตั้ง อัปเดต สำรองข้อมูล และตรวจ SHA-256 ที่
[docs/LOCAL_INSTALL.md](docs/LOCAL_INSTALL.md)

รวม 4 เครื่องมือไว้ในโปรแกรมเดียว หน้าต่างเดียว แถบเมนูด้านบนสลับได้ (เปิดตรงเข้าเครื่องมือแรก):

- 🔍 **Cabal Item ID Finder** — ค้นหา / ตรวจรหัสไอเทม (Aztek ID) จากเว็บ combo-interactive
- 📦 **Create Bundle** — สร้าง Bundle อัตโนมัติบนเว็บ aztek-tools
- 🎟️ **Create Item Code** — สร้าง Item Code + ชุดรางวัลบนเว็บ aztek-tools
- 🎉 **Create Event** — สร้าง Event (WINNER) จาก Monthly Plan บนเว็บ aztek-tools

เปิดโปรแกรมเข้า **Item Finder** (จุดเริ่ม pipeline) ทันที ไม่มีหน้า Home คั่น ทุกหน้าใช้ธีม
ttk `clam` ธีมเดียวไม่สลับ → นำทางลื่น ไม่หน่วง และ UI ของทุกเครื่องมือถูกสร้างล่วงหน้า
ตอนโปรแกรมว่าง (pre-warm) ทำให้กดเปิดครั้งแรกไม่ค้าง

## เวอร์ชันเว็บ (ทีมใช้ร่วมกัน)

นอกจากโปรแกรม desktop (tkinter) แล้ว มีเว็บแอป (FastAPI) สำหรับให้ทีมใช้ผ่านเบราว์เซอร์
แต่ละคนล็อกอินบัญชีของตัวเอง และเชื่อมเซสชัน Aztek ของตัวเองผ่านส่วนขยาย
Chrome — เซิร์ฟเวอร์รัน Chrome แบบ headless แยก context ต่อผู้ใช้ (ไม่แชร์โปรไฟล์)

ทั้ง 4 ขั้นตอนอยู่บนเว็บครบแล้ว — แถบบนสุดของทุกหน้าเดินตามลำดับนี้:

| หน้า | ทำอะไร | ส่งต่อ |
|---|---|---|
| `/` **Item Finder** | นำเข้าแผน → ค้นหา ID ไอเทม | ➡ คิวบันเดิล · ➡ ร่าง Item Code |
| `/bundles` **Create Bundle** | แก้/เพิ่มไอเทม แล้วสร้างทีเดียวทั้งคิว | ➡ เลข bundle ที่สร้างได้ |
| `/itemcodes` **Create Item Code** | 1 โค้ด = หลายชุดรางวัล (Fix / Server Generate) | — |
| `/events` **Create Event** | 1 อีเวนต์ = หลายชุดรางวัล ช่วงกิจกรรม + ช่วงรับรางวัล | — |

หน้า Item Code มี **“📂 Import ไฟล์แผน”** ของตัวเองด้วย — เปิดไฟล์ดูข้อมูลได้เลยไม่ต้องผ่านหน้าค้นหา
กด import แล้วจะให้ **เลือกแท็บ** ก่อน (ไฟล์เดียวมีหลายสิบกิจกรรม) ติ๊กเฉพาะที่จะทำ เอาเข้าคิวเฉพาะนั้น
— หน้าค้นหาไอเทมก็เก็บเฉพาะแท็บที่เลือกเหมือนกัน

ฟอร์ม Item Code บนเว็บตัดช่องที่ไม่ได้ใช้ออก: **ประเภทล็อกเป็น ALL เสมอ** · ไม่มี “จำกัดจำนวน”
ระดับ Item Code · ไม่มีคำอธิบายไทย/อังกฤษ (ปล่อยค่าเริ่มต้นของเว็บไว้ ไม่ไปเขียนทับ)
ส่วน **“จำกัดจำนวน Code” ของชุดรางวัลยังอยู่** — ติ๊กแล้วช่องจำนวนรวม/คงเหลือจะโผล่มาให้กรอก
เหมือนบนเว็บจริง

ช่องวันเวลาเป็น **ปฏิทิน 24 ชั่วโมง** ที่ทำเอง เพราะตัวของเบราว์เซอร์เลือกรูปแบบตามภาษาของเบราว์เซอร์
(เครื่องภาษาอังกฤษจะได้ AM/PM) ส่วนของ Aztek กับในไฟล์แผนเป็น 24 ชม. หมด

**ปุ่ม “➡ ส่งเข้าสร้าง Item Code”** (อยู่ในการ์ดนำเข้าไฟล์) อ่านเงื่อนไขที่อยู่เหนือตารางของรางวัล
— วันหมดอายุ · จำนวนโค้ด/ชุด · จำนวนชุด · เติมซ้ำได้ไหม — มากรอกให้เลย **ตารางของรางวัล 1 ตาราง = 1 Item Code**
ชื่อ = `<ชื่อกิจกรรม> - <ชื่อกลุ่ม/ตาราง>` ใช้ได้ตั้งแต่นำเข้าไฟล์เสร็จ ไม่ต้องรอค้นหาไอเทม

พอสร้างบันเดิลเสร็จแล้วกด “➡ สร้าง Item Code” จากหน้าบันเดิล เลข bundle จะไปเติมให้**ร่างของกลุ่มเดียวกัน**
ที่ค้างอยู่ในคิว ไม่สร้างโค้ดซ้ำใหม่

สิ่งที่ไฟล์ตอบไม่ได้ (วันหมดอายุอ่านไม่ออก · วันหมดอายุผ่านมาแล้ว · ชื่อไทยล้วนทำ slug ไม่ได้)
จะขึ้นเป็นคำเตือนใน Log ของหน้า Item Code แทนที่จะเดาให้

> เว็บคุยกับ Aztek **v2** ส่วน desktop คุยกับ v1 — หน้าตาฟอร์มคนละแบบ โค้ดจึงแยกกันอยู่
> (`web/itemcode_runner.py`, `web/event_runner.py`) ไม่ได้เรียกของ desktop มาใช้
>
> v2 ผูก bundle ได้ **ชุดรางวัลละ 1 อัน** (เลือกแล้วปุ่มเปลี่ยนเป็น “เปลี่ยน”)
> ถ้าเอกสารสั่งหลาย bundle ในรางวัลเดียว ให้แยกเป็นหลายชุดรางวัล

ทุกหน้ามี **“👁 เปิดหน้าเว็บดูก่อน”** ที่กรอกฟอร์มให้ครบแต่ **ไม่กดสร้าง** — ปุ่มสร้างจริง
จะยังกดไม่ได้ถ้ากรอกไม่ครบ (กัน Item Code / Event ที่ข้อมูลหายไปโผล่บนเว็บจริง)

- รันโลคัล: `uvicorn web.app:app --reload` แล้วเปิด `http://localhost:8000`
- โค้ดเว็บอยู่ใน `web/`
- เชื่อมเซสชัน Aztek ด้วย **bookmarklet** (ไม่ต้องลงส่วนขยาย) — ลากปุ่ม “เชื่อม Aztek” จากหน้า `/account` ไปไว้ที่แถบบุ๊กมาร์ก แล้วกดบนหน้า Aztek ที่ล็อกอินแล้ว
- deploy ขึ้น Render ฟรี: [docs/deploy-render.md](docs/deploy-render.md)

โปรแกรม desktop เดิมยังทำงานได้ตามปกติทุกอย่าง — เว็บเป็นทางเลือกเสริม ไม่กระทบของเดิม

### สถาปัตยกรรม (โครงพึ่งพาทางเดียว — ง่ายต่อการแก้/เพิ่ม tool)

```
all_for_cabal.py (launcher)
        │  TOOLS = [item_finder.TOOL, new_tool.TOOL, itemcode_tool.TOOL, event_tool.TOOL]
        ▼
   4 เครื่องมือ (แต่ละไฟล์ export ตัวแปร TOOL)
        │
        ▼
 ui_common.py · aztek_core.py · config.py   (ของกลาง — tool ไม่พึ่งกันเอง)
```

### เพิ่มเครื่องมือใหม่ (tool #5)

1. สร้าง `mytool.py` — คลาส `App(root, container=None, game_var=None, ...)` (ตาม convention เดิม;
   `container=None` = รันเดี่ยว, `game_var=None` = สร้าง StringVar ของตัวเอง)
2. ใช้ของกลาง: `from ui_common import C, make_button, ...` · `import aztek_core as core` · `import config as cfg`
3. ปลายไฟล์ export ทะเบียน:
   ```python
   from tool_registry import ToolSpec
   TOOL = ToolSpec(key='mytool', icon='✨', title='...', nav='✨  My Tool',
                   desc='...', boot='info',
                   make=lambda lc, fr: App(lc.root, container=fr, game_var=lc.game_var))
   ```
4. ใน `all_for_cabal.py`: `import mytool` แล้วเพิ่ม `mytool.TOOL` เข้า `TOOLS` (บรรทัดเดียว)
5. ใน `all_for_cabal.spec`: เพิ่ม `'mytool'` ใน `hiddenimports`

> launcher จะ derive เมนู/การ์ด/การสร้าง tool/การสลับธีม จากทะเบียนให้อัตโนมัติ — ไม่มีจุด hardcode ให้ลืม

## Import ไฟล์ Event / Prize เข้า Item Finder

ไฟล์ตารางรางวัล (เช่น `ITEM CODE ....xlsx`) ที่มีหัวคอลัมน์ **Item Kind / ItemOption /
DurationIndex / Display Name** อยู่กลาง sheet — import เข้าแท็บ **หลายชิ้น** ได้เลย:

1. แท็บ **หลายชิ้น** → ปุ่ม **🎁 Import Event/Prize** → เลือกไฟล์ `.xlsx`
2. ระบบสแกนทุก sheet (อ่านใน background) หาตารางไอเทม — รองรับ **หลายตารางต่อ sheet** และค่าที่เป็น `.0`
3. ถ้ามีหลาย sheet → เด้ง **หน้าต่างเลือก sheet** (คลิกเลือกหลายอันได้ ไม่ต้องกด Ctrl · โชว์จำนวนไอเทมต่อ sheet)
4. กด **Import ที่เลือก** → ไอเทมเข้าลิสต์ (ต่อท้าย + ตัด kind/opt/dur/name ซ้ำ) แล้วกด **🔍 ค้นหาทั้งหมด** เพื่อหา Aztek ID

> ดึงเฉพาะคอลัมน์ที่ใช้ค้นหา (Item Kind / ItemOption / DurationIndex / ชื่อไอเทม) —
> detect จาก **ชื่อหัวคอลัมน์** ไม่ยึดตำแหน่ง จึงรองรับไฟล์ที่คอลัมน์เลื่อนได้
> ชื่อไอเทมรองรับทั้ง **"Item Name"** (ให้ก่อน) และ **"Display Name"** · คอลัมน์ Amount ก็อ่าน
> ถ้า ItemKind บางตัวถูก Excel **format เป็นวันที่** (เก็บเป็น `5.0337837E7` = 50337837) ระบบจะ
> สั่ง openpyxl ไม่แปลงเป็นวันที่ → **กู้ค่าเลขคืนได้** (เดิมกลายเป็น `#VALUE!` ค่าหาย)
> ส่วน ItemKind ที่เป็น **สูตร lookup** ค่าที่ cache ว่าง จะ **ข้ามเฉพาะตัวนั้น ไม่ตัดตาราง** + log เตือน

**โหมด "แสดงผลบนเว็บ" (Deep Check):** ในแท็บ หลายชิ้น เลือกได้ว่าจะให้เข้าไปเช็ค checkbox
**"เปิดใช้งานการแสดงผลบนเว็บ"** ในหน้ารายละเอียดของแต่ละไอเทมไหม:
- **ทั้งหมด** — ไม่เข้าไปเช็ค (ค้นปกติ เร็วสุด)
- **มี (ติ๊ก)** — เอาเฉพาะไอเทมที่ checkbox **ติ๊ก**
- **ไม่มี (ไม่ติ๊ก)** — เอาเฉพาะไอเทมที่ checkbox **ไม่ติ๊ก**

> มี/ไม่มี จะเข้าไปเปิดหน้ารายละเอียดทีละไอเทม จึง **ช้ากว่า** แบบทั้งหมด

> **กันอ่านผิดตอนหน้ายังโหลดไม่เสร็จ:** Deep Check จะรอจนฟอร์มรายละเอียด **มีข้อมูลจริง**
> (ช่อง ItemKind มีเลข) และค่านิ่งก่อนอ่าน ถ้าโหลดไม่เสร็จจะรีโหลด 1 ครั้ง แล้วถ้ายังไม่มา
> จะ **ข้ามไม่นับผ่าน** (กันเคสฟอร์มเปล่าอ่านได้ web=ไม่ติ๊ก แล้วผ่านผิดๆ)

หน้า **ผลลัพธ์** เป็น **ตาราง** 3 คอลัมน์ (Aztek ID / ชื่อไอเทม / กลุ่ม) อ่านง่าย
คลิกเลือกได้หลายแถวโดยไม่ต้องกด Ctrl (คลิกซ้ำ = ยกเลิก) มีปุ่มเลือกทั้งหมด/ล้าง

**ความเสถียรของการค้นหา:** หลังกดค้นหา ระบบจะ **รอจนตาราง "มีข้อมูลจริงและนิ่ง"** ก่อนอ่าน
(ไม่อ่านตอนตารางว่างชั่วขณะระหว่างโหลด) และถ้าตารางว่างจริง (เน็ต/หน้าเว็บช้า) จะ **ลองใหม่อีกครั้ง**
— กันอาการ "บางทีเจอ บางทีไม่เจอ"

**ตัดซ้ำ แต่ยังรู้ว่าอยู่ตารางไหน:** ไอเทมที่ซ้ำ (kind/opt/dur/name เดียวกัน) จะถูกตัดเหลือ
ตัวเดียว **เพื่อค้นหาครั้งเดียว** แต่จะ **รวมรายชื่อกลุ่ม** ไว้ — ชื่อกลุ่มดึงจากแบนเนอร์บนสุด
ของแต่ละ section (เช่น `Participation`, `Fastest Guild`, `Lucky Winner`, `WINNER REWARDS`)
โดยข้ามข้อความ generic (Prize / Conditions / CODE EXPIRE ...) และไม่ใส่ชื่อ sheet
(เพราะค้นทีละ sheet) — เห็นได้ในลิสต์, หน้า **ผลลัพธ์** (« ... ») และคอลัมน์ **Groups** ตอน export

**เรียงผลตามชุด (ตรงตามเอกสาร):** หลังค้นเสร็จ ผลลัพธ์จะ **เรียงแยกตามชุด ตามลำดับในเอกสาร**
อัตโนมัติ (ไอเทมที่อยู่หลายชุดจะโผล่หลายแถว แถวละชุด) — เลือกทั้งบล็อกของชุดแล้ว **ส่งเข้าบันเดิล
ได้ตรงลำดับเอกสารเลย** · มีปุ่ม **↕ เรียงตามชุด** ในแท็บผลลัพธ์เผื่อสั่งเรียงเองอีกครั้ง

## ส่งไอเทมจาก Finder → เก็บเป็นคิว Bundle

1. ใช้ **Item Finder** ค้นหาไอเทมตามปกติ → ดูผลที่แท็บ **ผลลัพธ์**
2. **คลิกเลือกได้หลายชิ้นเลย ไม่ต้องกด Ctrl** (คลิกซ้ำ = ยกเลิก) — มีปุ่ม "เลือกทั้งหมด / ล้างที่เลือก" · ไม่เลือก = ทั้งหมด
3. กดปุ่ม **➕ ส่งไป Create Bundle**
4. เด้ง **หน้าต่างใหม่** ขึ้นมาให้กรอกข้อมูล bundle — **Item ID เติมให้อัตโนมัติ**
5. กรอกชื่อ / เลือก Type / ติ๊กส่งของทันที และวาง **qty กับ Tier** (ดูหัวข้อล่าง)
6. กด **เก็บเข้าคิว** → bundle ถูกเก็บไว้ในคิว (dropdown "เลือก bundle จากไฟล์")
7. ทำซ้ำได้เรื่อยๆ เก็บได้ **หลาย bundle** แล้วกด **"สร้างทุก bundle อัตโนมัติ"** ทีเดียว

> เปิดหน้าต่างเปล่าเองได้ด้วยปุ่ม **➕ เพิ่ม Bundle เข้าคิว** ในแท็บ Create Bundle

## เลือกเกม/เซิร์ฟ ครั้งเดียว ใช้ร่วมทุก tool

Dropdown **เลือกเกม/เซิร์ฟเวอร์** ถูก **sync ร่วมกันทุกเครื่องมือ** — เลือกที่ไหนก็เปลี่ยนพร้อมกันหมด
(รวมช่องเซิร์ฟในแท็บ "หลายชิ้น" ด้วย) — จำค่าล่าสุดไว้ใน prefs ไฟล์เดียว (`.aztek_prefs.json`)

## โฟลว Event → Bundle → Item Code

Item Finder (แท็บ "หลายชิ้น") มีสวิตช์ **โหมด: Event / Item Code** เป็นจุดเริ่มของทั้งคู่ —
เลือกโหมดแล้ว **Import** จะอ่าน template คนละแบบ และส่งต่อไปคนละเครื่องมือ (ไม่ข้ามกัน):

- **Item Code** = บังคับ Deep Check "ไม่มี" (ล็อก) → **ค้นหา ID** → ส่งบันเดิล → เติมใน **Create Item Code**
- **Event** = Import Monthly Plan (**template คนละแบบ**) → **ค้นหา ID เหมือนกันทุกอย่าง** → ส่งบันเดิล → เติมใน **Create Event**

ทั้งคู่ใช้ pipeline ค้นหา + ส่งบันเดิลชุดเดียวกัน ต่างแค่ **parser ของ template** และ**เครื่องมือปลายทาง**
(กลุ่มของ Event = ชื่อรางวัลแต่ละอัน · Create Event รวมกลุ่มตาม "ชื่อ Event" = 1 Event หลายชุดรางวัล)

ขั้นตอนทำ Item Code จากไฟล์ Event (แต่ละ **Code No.X = 1 Item Code**):

1. **Item Finder** โหมด Item Code → **Import Event/Prize** → ค้นหา ID
2. เลือกไอเทมของกลุ่ม (Code) นั้น → **➕ ส่งไป Create Bundle** → สร้าง 1 bundle
   ระบบ **จำ bundle id ไว้ตามกลุ่ม (Code)** ให้อัตโนมัติ
3. ไป **Create Item Code** → ปุ่ม **📥 เติมจาก Event** → เลือกกลุ่ม → ฟอร์มถูกเติมให้:

   | ช่อง | เติมจาก |
   |---|---|
   | ชื่อ / ชื่อชุดรางวัล | `ชื่อกิจกรรม` (แบนเนอร์ซ้ายบนระดับชีต เช่น VICI) + เว้นวรรค + `ชื่อรางวัล` |
   | ชื่อรางวัล (แต่ละ section) | แบนเนอร์ section ในคอลัมน์ Item Kind (เช่น "GM Slayer") · ถ้าไม่มีใช้เลข Code จาก CONDITIONS/Prize (เช่น "Code No. 1") |
   | slug | `ชื่อกิจกรรม-ชื่อรางวัล` (อังกฤษล้วน, ขีดกลาง) |
   | ประเภท Code | เจอ "Unique Code" → **Server Generate** |
   | ใช้งานต่อ 1 User | เจอ "Cannot be repeated / เติมซ้ำไม่ได้" → **1** (ทั้งระดับ Item Code + ชุดรางวัล) |
   | จำนวนชุดรางวัล | **1 ชุด (เจนรวม)** เมื่อ `set=1` / ไม่ซ้ำข้ามเซ็ต ("even different sets" / "ข้ามเซ็ตไม่ได้") / เติมซ้ำได้ ("can be repeated" / "เติมซ้ำได้") · **= Number[set] ชุด** เมื่อ "once per set" / **"เติมข้ามได้"** |
   | จำนวนโค้ด (num) ต่อชุด | เจนรวม = **Total** · เจนแยก = **codes/set** · ต่อท้ายชื่อด้วยเลขชุดถ้ามีหลายชุด |
   | +5 buffer | ใส่ **เฉพาะ 2 ชุดแรก** (ที่เหลือเลขเป๊ะ) |
   | เวลาสิ้นสุด | ถ้า CODE EXPIRE DATE เป็น **format ผิด** (เช่น "2 เดือน") → ไม่ capture ปล่อย default |

   > รองรับ template ทั้งภาษาอังกฤษและ**ภาษาไทย** (จำนวน [โค้ด/ชุด], จำนวน [ชุด], รวม, เงื่อนไขเพิ่มเติม)

## Create Event (จาก Monthly Plan)

**Event** ใช้ template คนละแบบกับ Item Code (`.../events/create`) — หน้าตาเหมือนกันแต่:

- **ประเภท = WINNER เสมอ**
- **จำนวนครั้งที่ใช้ได้ / จำนวนคงเหลือ = 0**
- ชุดรางวัลมีแค่: ชื่อ (ไทย/อังกฤษ) + Limited + ใช้ต่อ 1 User + **Bundle ID**
- **bundle_id อยู่ในไฟล์ template อยู่แล้ว** (คอลัมน์ Bundle ID) → ไม่ต้องหา ID / สร้าง bundle ใหม่

**เริ่มที่ Item Finder** → โหมด **Event** → **🎁 Import Event/Prize** เลือกไฟล์ Monthly Plan →
**เลือก sheet/Event** (หลายอันได้) → ส่งเข้าคิว → ไปแท็บ **Create Event** กด **📥 เติมจาก Plan**
→ เลือก Event → ฟอร์มถูกเติม: (หรือใช้แท็บ **นำเข้า Plan** ใน Create Event เองก็ได้)

| ช่อง | เติมจาก |
|---|---|
| ชื่อกิจกรรม | ค่าถัดจาก **"Event Name"** |
| ชื่อชุดรางวัล | แบนเนอร์ **"Reward: &lt;ชื่อ&gt;: N รางวัล"** → ตัด ": N รางวัล" ออก |
| เวลาเริ่ม/จบ กิจกรรม + รับรางวัล | แถว **"ระยะเวลากิจกรรม"** (`Start` วันที่+เวลา / `End` เวลา) |
| ประเภท / ครั้งที่ใช้ / คงเหลือ | WINNER / 0 / 0 |
| Bundle ID | **ไม่ดึงจากไฟล์** (คอลัมน์นอกกรอบ) → ค้น/ใส่เองบนเว็บ |

> - `End` ในไฟล์มักไม่มีวัน → ใช้วันเดียวกับ `Start`
> - ชื่อ Event ที่เป็น**ไทยล้วน** สร้าง slug อัตโนมัติไม่ได้ (a-z0-9- เท่านั้น) → กรอก slug เอง
   | เวลาเริ่ม | **วันปัจจุบัน 00:00:00 เสมอ** |
   | เวลาสิ้นสุด | CODE EXPIRE DATE (รองรับ datetime เต็ม / Excel serial / ไม่มีปี→ปีปัจจุบัน) |
   | bundles | bundle id ที่สร้างไว้ (ถ้ามี) |

4. ตรวจ/แก้ได้ทุกช่อง → **สร้าง + กดบันทึก**

> แท็บ "นำเข้า Excel" ของ Create Item Code เพิ่ม **scrollbar แนวนอนด้านล่าง** เลื่อนดูชื่อยาวๆ ได้

## กรอก qty / Tier ด้วยการวางจาก Excel (แยกช่อง)

หน้าต่างเพิ่ม Bundle มี **3 คอลัมน์แยกกัน**: `Item ID` · `จำนวน (qty)` · `Tier`
คัดลอกทีละคอลัมน์จาก Excel มาวางในแต่ละช่องได้เลย (ไม่ต้องพิมพ์) — แถวของทั้ง 3 ช่อง
จะจับคู่กันตามลำดับบรรทัด (บรรทัดที่ 1 ของทุกช่อง = ไอเท็มตัวเดียวกัน) เลื่อนพร้อมกันทั้ง 3 ช่อง

- ช่องจำนวนเว้นว่าง = `1`  ·  ไม่ใส่ Tier = `Common`  ·  ID ซ้ำถูกตัดอัตโนมัติ
- ในแท็บหลักยังมีช่องพิมพ์ `ID จำนวน Tier` บรรทัดเดียว (paste ทั้งแถวจาก Excel) ไว้แก้เร็วๆ ได้เหมือนเดิม

## Bundle แบบ RANDOM (เรทสุ่ม)

เมื่อเลือก **Type = RANDOM** ช่อง **"เรทสุ่ม"** จะโผล่ทั้ง 2 ที่ (ต่อไอเท็ม, ค่า `0.000 - 100.000`):
- **แท็บหลัก "รายการในบันเดิล"** — ช่องสีเหลืองทางขวาของกล่องรายการไอเทม (เรียงบรรทัดตรงกัน) วางจาก Excel ได้
- **หน้าต่าง popup** — คอลัมน์ที่ 4

ตัวสร้างบันเดิลจะกรอกค่านี้ลงช่อง "เรทสุ่ม" บนเว็บให้อัตโนมัติตอนสร้าง (ส่วน "เรทโชว์" ไม่ถูกแตะ)

> ⚠️ ช่องเรทสุ่มใน popup โผล่เฉพาะตอนตั้ง Type=RANDOM **ในตัว popup** — ถ้าตั้ง RANDOM ทีหลังบนแท็บหลัก
> ให้ใส่เรทสุ่มที่ช่องสีเหลืองบนแท็บหลักแทน · ถ้าสร้างทั้งที่เรทสุ่มไม่ครบ จะมีเตือนก่อน

- ถ้า RANDOM แต่บางไอเท็มยังไม่ใส่เรทสุ่ม จะมีเตือนก่อนเก็บเข้าคิว
- Template import รองรับคอลัมน์ `random_rate` แล้ว (ใส่เฉพาะแถวที่ `bundle_type = RANDOM`)
- ในช่องพิมพ์บรรทัดเดียว ใส่เรทสุ่มเป็น**ทศนิยม** ได้ เช่น `221960 1 Common 12.500`
- การกรอกบนเว็บ: หาการ์ดไอเทมผ่าน `data-rfd-draggable-id` + อ่านค่า Item ID ผ่าน JS
  (ช่องเป็น React controlled input ที่ไม่ reflect attribute) และเลือกช่อง "เรทสุ่ม"
  ที่เป็น `input[type=number][required]` — ไม่ไปโดน "เรทโชว์"

## Login จุดเดียว (แถบบนร่วม)

เปิดผ่าน All for Cabal จะมี **แถบบนร่วม** อยู่ทุกหน้า: `🎮 เกม/เซิร์ฟ` · `🔑 เข้าสู่ระบบ` ·
`ทดสอบ` · `ล้าง session` · สถานะ `● มี session / ○ ยังไม่ login` — **login ที่นี่ที่เดียว**
ใช้ได้ทุกเครื่องมือ (แต่ละ tool จะซ่อน dropdown เกม/ปุ่ม login ของตัวเองตอนเปิดผ่าน launcher;
ถ้าเปิด tool เดี่ยว ๆ ยังมีของตัวเองครบ)

**โฟลว์ส่งต่อ:** Item Finder → Create Bundle → หลังสร้าง bundle มีปุ่ม
`🎟️ ไปสร้าง Item Code` / `🎉 ไปสร้าง Event` พาไปสเต็ปถัดไป + ดึงข้อมูลเข้าให้อัตโนมัติ

เบื้องหลัง: ทุกเครื่องมือใช้ **Chrome profile เดียวกัน**
(`.cabal_chrome_profile` วางข้างไฟล์ .exe) เพราะเป็นเว็บเดียวกัน → **login ที่ตัวไหนก็ได้
ครั้งเดียว** อีกสองตัวใช้ต่อได้เลย

> เปิด browser login ทีละตัว (อย่าเปิดค้างพร้อมกันสองหน้าต่าง) เพราะ Chrome ล็อกโปรไฟล์ไว้ตัวเดียว

## หมายเหตุ

- Prefs (เกมที่เลือกล่าสุด) ใช้ **ไฟล์เดียว** `.aztek_prefs.json` ร่วมกันทุก tool แล้ว
- เครื่องมือจะถูกสร้างตอนกดเปิดครั้งแรก (lazy) เปิดโปรแกรมจึงเร็ว
- แก้จากต้นฉบับน้อยที่สุด: `App.__init__` รับ `container` (ฝัง UI) และ Item Finder รับ
  `on_send_to_bundle` (callback ส่งไอเทม) — ถ้าไม่ส่งพารามิเตอร์เหล่านี้ ยังรันเดี่ยวได้เหมือนเดิม
- Item Code / Event จะ **ไม่กดบันทึกอัตโนมัติ** ถ้ากรอกช่องบังคับไม่ครบ (กันข้อมูลหายถูกสร้างบนเว็บจริง) —
  ขึ้น log สีเหลืองให้ตรวจ/กดเอง; และจะไม่ทำงานถ้ายังไม่ได้ login (กดปุ่มเปิดหน้า Login ก่อน)
- เปิด browser ได้ทีละ tool (browser lock) — ถ้ามี browser ค้างอยู่ อีก tool จะเตือนให้ปิดก่อน
